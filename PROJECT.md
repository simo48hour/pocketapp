# Project Management & Roadmap

PocketApp is an open-source AI full-stack development platform. This document outlines how features, issues, and contributions are organized.

## Issue Tracking & Milestones

All roadmap items, planned features, and community bug reports are tracked openly in GitHub Issues and Discussions:

- **Issues & Bug Reports**: [GitHub Issues](https://github.com/simo48hour/pocketapp/issues)
- **Discussions & Ideas**: [GitHub Discussions](https://github.com/simo48hour/pocketapp/discussions)

## Strategic Areas (Roadmap)

1. **PocketBase Backend Integration**:
   - Automated schema migrations and collection creation.
   - Enhanced authentication templates and rule generators.
   - Real-time event subscription helpers.

2. **Developer Experience & Tooling**:
   - WebContainer performance optimizations.
   - In-browser debugging and visual inspector improvements.
   - 1-click Docker and full-stack ZIP export enhancements.

3. **Multi-Model & BYOK Support**:
   - Continuous support for latest frontier models (Claude 3.7, GPT-4o, Gemini 2.0).
   - Local LLM inference improvements (Ollama, LM Studio).

## Contributing Features

- Fork the repository and open a feature branch.
- Submit a Pull Request with a clear description of the feature or bug fix.
- Make sure unit tests pass (`pnpm run test`) and typecheck passes (`pnpm run typecheck`).
